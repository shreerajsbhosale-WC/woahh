Place your font files here (woff2 or otf), named exactly:

  Moonscape-Demo.woff2 / .otf   -> wordmark ("LIMITLESS")
  Rectinos.woff2 / .otf         -> headings
  NaruSans-Demo.woff2 / .otf    -> body text
  Westmount.woff2 / .otf        -> labels, buttons, eyebrows

Until they are added, the site falls back to Space Grotesk / Inter automatically.
To change which font does what, edit the --font-* variables at the top of src/styles.css.
